## 📱 Responsive Design Architecture

This portfolio is **fully responsive and mobile-optimized** across all device sizes:

### Device Breakpoints

| Device Type | Screen Size | Optimizations |
|-------------|------------|---------------|
| **Extra Small (XS)** | < 375px | iPhone SE, small Android phones |
| **Small (SM)** | 375px – 480px | Standard mobile phones |
| **Medium (MD)** | 481px – 768px | Tablets, large phones (landscape) |
| **Large (LG)** | 769px – 1024px | Tablets (landscape), small laptops |
| **Extra Large (XL)** | 1025px – 1280px | Desktop monitors |
| **2XL** | > 1280px | Wide desktop screens |

### Mobile-First Responsiveness Features

✅ **Touch-Optimized Interactions**
- All buttons and interactive elements: minimum 44×44px (Apple HIG standard)
- Touch targets properly spaced to prevent accidental taps
- No hover states on touch devices

✅ **Flexible Layouts**
- Single-column layouts on mobile
- Two-column grids on tablets
- Multi-column layouts on desktop
- CSS Grid and Flexbox for adaptive spacing

✅ **Typography Scaling**
- `clamp()` functions for fluid font sizing
- Font sizes adjust smoothly between breakpoints
- Maintained readability across all screen sizes

✅ **Image Optimization**
- Responsive images with `srcset` and `sizes`
- WebP format with PNG fallbacks
- Lazy loading for below-the-fold content
- Optimized for different pixel densities

✅ **Navigation Adaptations**
- Desktop: Horizontal navigation bar
- Mobile: Hamburger menu with smooth animations
- Smooth scrolling between sections

✅ **Performance Optimizations**
- Code splitting with lazy-loaded routes
- Reduced animations on low-end devices
- Efficient CSS with utility-first approach
- Image compression and optimization

## 🚀 Getting Started

### Prerequisites
- **Node.js** v16+ ([Download](https://nodejs.org))
- **npm** v8+ or **yarn** v1.22+

### Installation & Setup

1. **Clone the Repository**
```bash
git clone https://github.com/cupidbity/portfolio-template.git
cd portfolio-template/portfolio-template-main
```

2. **Install Dependencies**
```bash
npm install
# or
yarn install
```

3. **Set Up Environment Variables**
```bash
cp .env.example .env
```

4. **Edit `.env` with Your Information**
```env
# Social Links
VITE_GITHUB_URL=https://github.com/purvathorat
VITE_LINKEDIN_URL=https://linkedin.com/in/purva-thorat
VITE_EMAIL=purva@example.com

# Repository Links
VITE_GITHUB_PROJECT1_URL=https://github.com/purvathorat/purrrch
VITE_GITHUB_PROJECT2_URL=https://github.com/purvathorat/crestfield-law
# ... etc
```

5. **Start Development Server**
```bash
npm run dev
# or
yarn dev
```

The site will be available at `http://localhost:5173`

## 🎨 Customization Guide

### 1. **Update Personal Information**

#### Page Title & Meta
Edit `index.html`:
```html
<title>Purva Thorat — Frontend Developer</title>
<meta name="description" content="Portfolio of Purva Thorat, a frontend developer...">
```

#### Navigation & Branding
Edit `.env`:
```env
VITE_GITHUB_URL=your-github-url
VITE_LINKEDIN_URL=your-linkedin-url
VITE_EMAIL=your-email@example.com
```

Update `src/components/section/Navigation.tsx`:
- Change "Purva Thorat" to your name

Update `src/components/Footer.tsx`:
- Update copyright year and name

### 2. **Customize Hero Section**

Edit `src/components/section/About.tsx`:
```tsx
// Update greeting text
<AsciiMorphText text="Hi, I'm Your Name" />

// Update roles in typewriter carousel
const roles = [
  'Your Role 1',
  'Your Role 2',
  'Your Role 3',
  'Your Role 4',
];

// Update about text
<p>Your about paragraph here...</p>
```

### 3. **Add Your Projects**

Edit `src/components/section/Projects.tsx`:
```tsx
const projects = [
  {
    title: "Your Project",
    description: "Brief project description",
    technologies: ["React", "TypeScript", "Tailwind"],
    emoji: "🎨",  // Use any emoji
    detailsUrl: "https://your-project.com",
    githubUrl: "https://github.com/yourname/your-project"
  },
  // ... more projects
];
```

### 4. **Update Education Timeline**

Edit `src/components/section/Experience.tsx`:
```tsx
const experiences = [
  {
    title: "Your Degree",
    company: "University Name",
    location: "City, State",
    period: "2023 – 2025",
    description: ["Your achievement 1", "Your achievement 2"]
  },
  // ... more education entries
];
```

### 5. **Update Skills**

Edit `src/components/section/Skills.tsx`:
```tsx
const skills = [
  'JavaScript',
  'React',
  'TypeScript',
  // ... your skills
];
```

### 6. **Add Certifications**

Edit `src/components/section/Certifications.tsx`:
```tsx
const certificates = [
  {
    emoji: '🎓',
    title: 'Your Certification',
    issuer: 'Issuing Organization',
    date: 'Month, Year',
    credentialUrl: 'https://verify-credential.com',
    pdfUrl: '/your-cert.pdf'
  },
  // ... more certs
];
```

Place PDF files in `public/` folder.

### 7. **Upload Images**

- **Journal Background:** Replace `src/assets/journal.PNG`
- **Profile Illustration:** Replace `src/assets/purva_illustration.png`
- **Resume:** Place at `public/resume.pdf`
- **Certificates:** Place PDFs in `public/` (e.g., `public/cert-nodejs.pdf`)

### 8. **Customize Theme Colors**

Edit `src/styles/colors.ts`:
```ts
export const colors = {
  pink: {
    50: '#FFF5F7',
    500: '#C88B95',
    // ... modify hex values
  },
  // ... other color definitions
};
```
